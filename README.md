# 時間割コマ管理ツール

新潟第一中学校・高等学校の時間割データを内包した単一HTMLウェブアプリです。
オフライン動作可能で、PC・タブレット・スマホのブラウザで開けば即起動します。

## 機能

| タブ | 内容 |
|---|---|
| ① 欠課対応(代講検索) | 欠勤教員＋曜日＋時限を指定 → 空きコマ教員を「同教科→関連→その他」の優先順でリスト化 |
| ② コマ移動・入替 | 単一教員のコマ移動可否判定 + 2教員のコマ入替シミュレーション(連鎖退避手順・途中退避コマを可視化) |
| ③ 全体表 | 教員別/学年・クラス別の表示。セルクリックで欠課対応にジャンプ |
| ④ 教員マスタ検索 | 名前・教科で絞り込み、教科別コマ数・空きコマ数集計 |
| ⑤ データ取込 | CSV/TSV貼付 + サンプルデータ読込 + プレビュー |

## データの保存

`localStorage` に保存されるので、ブラウザで一度開けば次回以降もデータが残ります。
89名のデータは `index.html` 内に焼き込まれているため、初回起動時から入力不要です。

## ファイル構成

- `index.html` — 本体(331 KB、外部依存ゼロ)

外部 CDN・外部 CSS・外部 JS の参照は一切ないため、ネット未接続の校内端末でも動作します。

## 連動コマの操作ルール

「コマ移動・入替」タブで「移動可能」と表示されても、連動して動かすコマがリスト表示されます。
必ず **外側から順に** 動かすこと。手順を破ると中間状態で授業が宙に浮きます。
